# Native kernel comparative research

C, Rust and existing C# AvcRandomAccess classifier: exact same packed length-prefixed input, same malformed-record contract, 4000 deterministic differential cases, actual encoded open/closed GOP samples, 100 warm-up calls, 7 reverse-order repetitions per language, 500 batch calls per repetition, pinned data for native calls, matching checksum. Compilation and input preparation excluded. The data repetition is a microbenchmark (hot cache), not an entire encoder benchmark. C compiled locally with GCC 14.2 and 4000 independent Python reference cases passed; C# and Rust are not available locally and await CI. Native FFI inputs must be valid pinned readable buffers; C/Rust are never loaded by desktop production code. No external crate, no packaging/runtime change. Compare medians/variation and estimate end-to-end ceiling before any integration. Rust library speed is an empirical question, not an assumption. Linux-only first comparison; Windows ABI/build/distribution remains separate. Do not equate parser speed with video codec speed.
