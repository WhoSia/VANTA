# VANTA first-pass decision model — 2026-11-26

Research prioritization, not release authorization. Hard integrity/compatibility/license/CI gates override all scores; owner acceptance is an external dependency. Do not treat research and deployment as identical decisions. Inputs are explicit subjective 0–1 utility judgments, not measured reliability or empirical probabilities. Anchors: 0 adverse/no benefit or infeasible; .5 limited/uncertain benefit or moderate effort; 1 high benefit or low effort; all axes favor higher. Each row gives an evidence rationale and uncertainty width; uncertainty is a sensitivity interval, not a confidence interval. Twelve axes in four groups: user impact, coverage, workflow speed potential; integrity gain, failure reduction, rollback ease; implementation feasibility, maintenance ease, distribution ease; decision relevance, testability, time efficiency. Evidence gap and current readiness are recorded separately from value; avoid rewarding unproven candidates as implemented. Grouping reduces but cannot eliminate double counting.

Inspired by SMAA-2 (https://doi.org/10.1287/opre.49.3.444.11220), robust ordinal regression survey (https://doi.org/10.1016/j.ejor.2024.07.038), decision sensitivity (https://doi.org/10.1016/j.asoc.2025.114335) and value of information (https://doi.org/10.1287/deca.2024.0187). Not a full implementation of any cited method. Four explicitly chosen profiles equally represented; bounded group-weight perturbation and Dirichlet(1,1,1) within-group weights, common group shock + candidate-specific shock + axis-specific shock. Fixed seed 12,000 scenarios. Mean, q05/q95 utility, rank acceptability, top-3 share, pairwise win fractions, mean/p95/max sampled regret, central Pareto set and perfect-scenario-information gap. The latter is E[max U]-max E[U] under assumed scenarios (includes preferences); not EVSI, real-world VOI or money. Max sampled regret is not a certified worst-case bound. No promotion on these scores. Required corpus repair first; owner action remains separate. Reassess with actual trial data, sensitivity to priors, alternate noncompensatory model and explicit observation model before any claimed calibrated EVSI. No cross-project RITHM changes.

Run node docs/decision/model.mjs; output is deterministic from inputs.json. results.json is generated snapshot. Actual simulation executed in JS during development, Node file execution and test wrapper separately pending CI/local runtime. Do not use as a production planner.
