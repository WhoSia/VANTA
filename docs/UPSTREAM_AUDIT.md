IDR is only a candidate, not proof of random-access correctness; actual frame comparisons are needed. No production routing change, external library, or license dependency.

Use batch ABI and actual existing managed classifier, not an intentionally slow baseline. Native C/Rust originals, no copied upstream code or third-party crate, no runtime dependency. Amdahl bound: if measured replaceable stage share p and kernel speed ratio s, ideal overall speedup 1/(1-p+p/s) before extra interop; microbench cannot prove workflow gain. Benchmark sources and limitations in docs/research and tests/native.
