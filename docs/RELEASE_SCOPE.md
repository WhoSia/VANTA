# Finite product scope

VANTA is a personal Windows compression utility, not a media suite or a perpetual research project.

1.0 exit gates: drag/drop one or multiple videos; bounded independent batch encoding with per-file plans, collision-safe names and failure isolation; three feasible estimated plans (or fewer with explanation); editable supported encoding settings; progress and cancellation; clear dependency discovery; no overwrite; continuous encoding; decoded output validation and A/V regression fixtures; Windows acceptance; measured app and dependency footprint. No known critical/high defects. Document unsupported inputs and remaining limitations.

Exclude: editing, download, AI, automatic or unverified chunk concatenation, accounts, telemetry, background services, databases, plugin system, endless optimization. Defer GPU/AV1, sample quality estimation and extra container support unless required for core usability. Freeze scope when gates pass. Maintenance only for defects/security/compatibility.

Decision vectors: (user value, implementation coverage, verified evidence, integrity confidence), separately scored; no arithmetic ranking. A release gate cannot be compensated by other scores. 0 means absent or unverified; subjective estimates are not measured reliability.

Optional owner-requested acceleration: explicitly selected video-only two-part CFR prototype; continuous default, original audio mapped once, same publication gate. Not a required stable release feature if speed/quality/integrity evidence is inadequate. No uncontrolled research expansion.

0.4.0 approved exception: bounded, measured multi-segment encoding research and adaptive selection, only when matched quality/size, resource and integrity gates pass. Continuous fallback remains default until evidence warrants a change. This does not expand to downloader/media editing or unverified formats. See PROPOSAL_0.4.0.md and ACCEPTANCE_0.4.0.md.
